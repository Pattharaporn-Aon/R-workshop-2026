# Solutions to the exercises

Solutions to the three exercises of the workshop
*Practical Data Analysis and Forecasting with R*.

| File | Exercise |
|---|---|
| `exercise1.R` | Exercise 1 — Figures with ggplot2 (Day 1 afternoon) |
| `exercise2.R` | Exercise 2 — Statistical tests (Day 2 morning) |
| `exercise2_output.txt` | Console output of `exercise2.R`, for checking your answers |
| `exercise3.R` | Exercise 3 — Time series and forecasting (Day 2 afternoon) |
| `figures/` | Every figure produced by `exercise1.R` and `exercise3.R`, at 300 dpi |

Each script runs on its own and reads the data directly from GitHub.
`exercise1.R` and `exercise3.R` save their figures into a `figures` folder
inside your working directory (`getwd()`).
